# Instagram Keyword Crawler

Search Instagram hashtags by keywords, collect post info, export to Excel.

## Quick Start

1. Edit `keywords.txt` with your hashtags (no # needed, e.g. `leatherbag,leatherbags`)
2. Double-click `run.bat`
3. Login to Instagram when browser opens (scan QR or account)
4. Results saved in `导出结果/` folder

## What it collects

- Author
- Caption
- Likes, comments
- Post date
- URL

Requires Instagram login (one time).
